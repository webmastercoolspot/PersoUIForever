# PersoUIForever
Amélioration de l'interface de base de blizzard pour WoW Forever

L'Addon a pour fonctionnalité : 

• 8 barres d'action masquées, visibles au survol/pickup/grimoire/métiers (+ véhicule pour la barre 1) ;

• Dark mode des bordures de boutons (compatible avec Trinket Master et les emplacement de bijoux de Item Rack) ;

• Compteur de FPS sous la minimap sans Ctrl+R ;

• Bouton Social déplaçable, bouton véhicule autonome visible uniquement en trajet ;

• Fix des icônes CC sur les nameplates (échelle et écart réglables) ;

• Fix de la barre furtif voleur via contrôleur sécurisé ;

• Panneau d'options organisé en 5 sections avec défilement, tout sauvegardé ;

• Boucle optimisée à 10 passages/s avec calculs mutualisés.

Ces fonctionnalités sont activables/désactivables dans les options de l'addon du jeu :
